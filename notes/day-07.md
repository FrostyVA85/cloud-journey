# Day 7 - Github: putting my work online

## Ideas
- A remote is a copy of my repository on another computer
- Mine is on Github and its nickname is origin
- Committing saves on my computer only
- Nothing is public until I push

## The cycle now
1. Edit and save
2. `git status`
3. `git add <file>`
4. `git commit -m "message"`
5. `git push`
