## In my own words
- An IP address is the number that identifies one device's connection to a network
- The network part and the host part are parts of an IP address. The first part names the network and the rest names one device on it
- A private address is an address that is used within a private network and are never sent through the internet
- A public address is an address that is unique in the whole world and can be reached through the internet
- My home has one public address
- DHCP is Dynamic Host Configuration protocol and is used to automatically assign a unique IP to each device in the network
- 127.0.0.1 is the localhost or the loopback address. Essentially it is the same device or loop
- An address beginning 169.254 means that it is self-assigned since it can't communicate with other devices in the network
