# Day 2 - Files, paths and extensions

## What a file is
- A file is a named row of bytes kept in storage
- The **extension** is the label after the last dot
- Plain text files contain characters and nothing else

## Paths
- **Absolute**: starts from the drive, like `C:\Users\Alvin`
- **Relative**: starts from where I am, like `notes\day-02.md`
- `.` is this folder, `..` is the folder above, `~` is home

## Commands
```
code .
code notes\day-02.md
```
