My Computer

- Memory (the desk): 64 GB DDR5
- Disk (the filing cabinet): 932 GB



Commands I learned


- whoami	= which user am I
- hostname	= the name of this computer
- pwd		= which folder am I in
- ls		= list what is in this folder
- cd		= change folder (cd .. = up one, cd \~ = home)
- mkdir	= make a new folder
- cat		= show what is in a file
- cls		= clear the screen
