# Day 3 - Managing files from the terminal

## Commands
- `cp source destination` = copy (two files afterwards)
- `mv source destination` = move, or rename if the folder stays the same
- `rm name` = delete for good - there is no recycle bin
- `rm folder - recurse` = delete a folder and all inside it
- `set-content filename content` = set the content for the filename with the content written at the last line
- `cat filename` = read the contents of the filename
- `h` = history of every command you have typed in the terminal window. Short for "history"

## Wildcards
- `*` = any characters, so `*.txt` is every .txt file
- `?` = exactly one character

## Before I delete anything
1. `pwd` - am I where I think I am?
2. `ls` - with the same pattern - is this what I mean?
3. Add `-whatiff` and read the rehearsal

## Shortcuts for VS Code
- `ctrl + K` then press `V` = create a split screen preview of what I am typing in the .md file editor
- `ctrl + S` = save current edited text
- `ctrl + ~` = open or close the terminal window at the bottom of the screen
